Sesi 2: Pengetahuan Bahasa · Tata Bahasa & Pemahaman Bacaan (言語知識（文法）・読解)

Bagian A: Pengetahuan Bahasa · Tata Bahasa (言語知識（文法）)

問題1　つぎの文の（　　　）に入れるのに最もよいものを、1・2・3・4から一つえらびなさい。

Soal 1: Pilihlah satu jawaban yang paling tepat (1, 2, 3, atau 4) untuk diisikan ke dalam tanda kurung (　　　).

1　寝ね坊ぼうした夫おっとは、ご飯（　　　）食べずにあわてて家を出て行った。

  1. も (pun / bahkan)
  2. で (di / dengan)
  3. に (ke / pada)
  4. の (kepunyaan)

Terjemahan: Suami saya yang bangun kesiangan pergi meninggalkan rumah dengan tergesa-gesa tanpa makan nasi ( pun ).

2　この島は、野菜（　　　）魚もおいしいことで有名です。

  1. であるにもかかわらず (meskipun merupakan)
  2. ばかりではなく (tidak hanya ..., tetapi juga)
  3. なせいで (gara-gara / akibat)
  4. ほど (sampai tingkat / se-)

Terjemahan: Pulau ini terkenal karena ( tidak hanya ) sayurannya, ikannya pun enak.

3　久しぶりにふるさとに帰ったが、（　　　）母の料理はおいしかった。

  1. 相変わらず (tetap seperti biasa / tak berubah)
  2. 決して (sama sekali tidak (diikuti bentuk negatif))
  3. いつも (selalu)
  4. そんなに (sebegitu / se- itu)

Terjemahan: Setelah sekian lama saya pulang ke kampung halaman, dan ( seperti biasa ) masakan ibu tetap lezat.

4　甘あまいものが好きな（　　　）、妹はチョコレートなどのお菓か子しを全く食べない。

  1. わたしをきっかけに (berawal dari saya / dengan saya sebagai pemicu)
  2. わたしとともに (bersama saya / seiring dengan saya)
  3. わたしに対して (berkebalikan dengan saya / terhadap saya)
  4. わたしにとって (bagi saya)

Terjemahan: ( Berkebalikan dengan saya ) yang menyukai makanan manis, adik perempuan saya sama sekali tidak makan camilan seperti cokelat.

5　一年（　　　）発表される彼かれの小説は、どれもすぐ売り切れになる。

  1. にあたって (menjelang / dalam rangka)
  2. ごとに (setiap (interval))
  3. の際さいに (pada saat / ketika)
  4. に先立って (sebelum / mendahului)

Terjemahan: Novel-novelnya yang diterbitkan ( setiap ) satu tahun sekali, semuanya langsung terjual habis.

6　（学校で）
生徒「先生、わたし行きたい高校に合格できるのか不安なんです。」
先生「大だい丈じょう夫ぶ。松まつ井いさんはこんなに（　　　）、きっと合格できるよ。」

  1. 頑がん張ばっているはずなのに (padahal seharusnya sedang berusaha)
  2. 頑がん張ばるとしても (kalaupun berusaha)
  3. 頑がん張ばるだけ (hanya/sekuat tenaga berusaha)
  4. 頑がん張ばってるんだから (karena sedang berusaha (memberi penekanan/alasan kuat))

Terjemahan: (Di sekolah)
Murid: "Pak/Bu Guru, saya cemas apakah bisa lulus masuk SMA yang saya inginkan."
Guru: "Tenang saja. ( Karena Matsui sudah berusaha ) sekeras ini, kamu pasti bisa lulus kok."

7　会社から家に帰ると、玄げん関かんの鍵かぎが（　　　）だった。寝ね坊ぼうして急いで出てしまったからだろう。

  1. 開いて以来 (sejak terbuka)
  2. 開きつつ (sambil terbuka)
  3. 開いたまま (masih dalam keadaan terbuka (dibiarkan tidak terkunci))
  4. 開くばかり (hanya terbuka terus)

Terjemahan: Ketika pulang ke rumah dari kantor, pintu depan ternyata ( dibiarkan tidak terkunci/terbuka ). Mungkin karena bangun kesiangan dan keluar dengan terburu-buru.

8　（会社で）
部長「来年発売する新商品の資し料りょうは完成したのか。」
